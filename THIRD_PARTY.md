# Third-party source / provenance

Current reconstruction checkpoint: `v1.7.3`.

The repository uses original build4100 binaries supplied for local compatibility analysis as an immutable runtime/static oracle under `runtime/original/`.

External Source Engine trees are research/donor references and are not automatically equivalent to CSS v34/build4100. The current main full-source donor is `dougrattman/SourceEngine2007`; old Source SDK 2006 / Episode One trees remain important for era-correct public ABI.

Some full-engine source repositories may have provenance/licensing constraints. Before redistribution of a derived source tree, independently review licenses, notices and provenance. The reconstruction/version state does not assert redistribution rights for third-party source.
